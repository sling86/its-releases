## Setup

```bash
its m365 setup           # Interactive wizard
its m365 setup --check   # Check configuration status
its m365 setup --reset   # Re-run setup (overwrite config)
```

### Required Environment Variables

| Variable | Description |
|----------|-------------|
| `TENANT_ID` | Microsoft Entra tenant ID (same as Entra provider) |
| `CLIENT_ID` | App registration client ID (same as Entra) |
| `CLIENT_SECRET` | App registration client secret (same as Entra) |

m365health reuses the same Graph API credentials as the Entra provider — no additional secrets needed. The app registration needs these **additional API permissions**: `ServiceHealth.Read.All` (health overviews + issues) and `ServiceMessage.Read.All` (message centre). Grant admin consent after adding them.

### health

> Source: `src/providers/m365health/commands/health.ts`

| Command | Description |
|---------|-------------|
| `its m365 health overview` | Per-service health status across the tenant (Exchange, SharePoint, Teams, etc). The fast 'is it us or Microsoft?' check. |

#### `its m365 health overview`

Per-service health status across the tenant (Exchange, SharePoint, Teams, etc). The fast 'is it us or Microsoft?' check.

**Examples:**

```bash
its m365 health overview

# Show only services not operational
its m365 health overview --filter status=degradation
```

#### `its m365 health issues`

Service incidents and advisories. Use --active to hide resolved ones, --service to scope to one service.

**Flags:**

| Flag | Alias | Description | Default |
|------|-------|-------------|---------|
| `--service` | `` | Filter by exact service name (e.g. Exchange Online) | — |
| `--active` | `` | Only unresolved issues | — |

**Examples:**

```bash
its m365 health issues

# Only open incidents and advisories
its m365 health issues --active

its m365 health issues --service "Exchange Online"
```

#### `its m365 messages`

Message-centre posts — planned changes, new features, action-required items. Use --days to show only recent posts.

**Flags:**

| Flag | Alias | Description | Default |
|------|-------|-------------|---------|
| `--days` | `` | Only posts modified in the last N days | — |

**Examples:**

```bash
its m365 messages

# Posts from the last 30 days
its m365 messages --days 30
```
